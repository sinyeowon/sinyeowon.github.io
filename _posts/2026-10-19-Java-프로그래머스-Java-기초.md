### 몫 구하기

<a class="notion-mention" href="https://school.programmers.co.kr/learn/courses/30/lessons/120805">Programmers Java 기초</a>

Java에서 몫을 구하기 위해서는 `/`를 사용해야한다.

정수 / 정수 → 정수값 몫을 반환하는데

실수 / 정수 → 와 같이 하나라도 실수라면 실수값 몫을 제공한다.

Java에서 `//`기호는 주석을 의미하기 때문에 Python에서와 같이 `//`로 몫을 구할 수 없다.

### 분수의 덧셈

<a class="notion-mention" href="https://school.programmers.co.kr/learn/courses/30/lessons/120808">Programmers Java 기초</a>

```java
class Solution {
    public int[] solution(int numer1, int denom1, int numer2, int denom2) {
        int[] answer = new int[2];
        
        answer[0] = numer1*denom2 + numer2*denom1;
        answer[1] = denom1 * denom2;
        
        while(answer[0] != 1) {
            for(int i = answer[1]; i>=1; i--) {
                if (answer[0] % i == 0 && answer[1] % i == 0) {
                    answer[0] /= i;
                    answer[1] /= i;
                
                }
            }
        }
        
        return answer;
    }
}
```

- 처음 코드의 오류
    - 기약 분수가 된다고 해서, 분자가 다 1이 되는 것은 아니다.
        - 분자가 1이 아니라도 기약 분수가 되면 반복을 종료하도록 해야한다.

    - 약분하려면 분자와 분모 중 더 작은 값을 찾는 것이 우선이다.

    - 또한, 분모 수에서 1까지 반복하는 for문에서 1은 약분에서 의미가 없으므로 확인할 필요가 없다.

    ```java
    class Solution {
        public int[] solution(int numer1, int denom1, int numer2, int denom2) {
            int[] answer = new int[2];
            
            answer[0] = numer1*denom2 + numer2*denom1;
            answer[1] = denom1 * denom2;
            
            for(int i = Math.min(answer[0], answer[1]); i>=2; i--) {
                if (answer[0] % i == 0 && answer[1] % i == 0) {
                    answer[0] /= i;
                    answer[1] /= i;
                    break;
                }
            }
            
            return answer;
        }
    }
    ```

- 수정 후 코드
    - **최대공약수로 한 번만 나누면 기약분수가 됨** → `while`문이 필요 없다.

    - `Math.min()` 을 사용 → 분자와 분모 중 작은 값 반환

### 최빈값 구하기

<a class="notion-mention" href="https://school.programmers.co.kr/learn/courses/30/lessons/120812">Programmers Java 기초</a>

#### 내 풀이

```java
class Solution {
    public int solution(int[] array) {
        int[] answer = new int[1000];
        
        for(int i = 0; i<array.length; i++) {
            
            answer[array[i]] += 1;
        }
        
        int[] max = new int[3]; // 0: max 값 1: max 인덱스 2: 그 전 max 값
        max[0] = 0;
        
        for(int i = 0; i<answer.length; i++) {
            if(answer[i] > max[0]) {
                max[0] = answer[i];
                max[2] = answer[i];
                max[1] = i;
            } else if (answer[i] == max[0]) {
                max[2] = -1;
            }
        }
        
        if (max[2] != -1) {
            return max[1];
        } else {
            return -1;
        }
    }
}
```

#### 더 나은 풀이

```java
class Solution {
    public int solution(int[] array) {
        int[] count = new int[1000];

        for (int num : array) {
            count[num]++;
        }

        int max = 0;
        int answer = 0;

        for (int i = 0; i < count.length; i++) {
            if (count[i] > max) {
                max = count[i];
                answer = i;
            } else if (count[i] == max) {
                answer = -1;
            }
        }

        return answer;
    }
}
```

- 향상된 for문 사용<br>
    `for(int num : array)`를 사용해 배열의 요소를 하나씩 꺼내서 num에 대입

- max 배열 대신 변수 사용
    - 별도의 중복 확인을 위해 배열을 만들었었는데, 필요하지 않기 때문에 변수로 바로 최빈값 확인 가능

    - 끝까지 for문을 돌면서 최빈값이 중복되면 -1, 저장해둔 max 값보다 새로운 값이 더 크면 다시 최빈값으로 저장

#### 다른 풀이

```java
import java.util.HashMap;

class Solution {
    public int solution(int[] array) {
        HashMap<Integer, Integer> map = new HashMap<>();

        for (int num : array) {
            map.put(num, map.getOrDefault(num, 0) + 1);
        }

        int max = 0;
        int answer = 0;

        for (int num : map.keySet()) {
            int count = map.get(num);

            if (count > max) {
                max = count;
                answer = num;
            } else if (count == max) {
                answer = -1;
            }
        }

        return answer;
    }
}
```

- `HashMap` 활용<br>
    문제에서는 배열을 사용하는 게 더 간단하지만, 숫자의 범위가 크거나 음수가 포함된다면 `HashMap`을 사용하는 방법도 있음

    `map.put(num, map.getOrDerfault(num, 0) + 1);` → `getOrDefault(num, 0)`은 해당 숫자가 이미 저장되어 있으면 기존 등장 횟수를 가져오고, 없으면 0을 반환한다.

### 짝수는 싫어요

<a class="notion-mention" href="https://school.programmers.co.kr/learn/courses/30/lessons/120813">Programmers Java 기초</a>

#### 풀이

```java
import java.util.ArrayList;
import java.util.Arrays;

class Solution {
    public int[] solution(int n) {
        ArrayList<Integer> array = new ArrayList<>();
        
        for(int i = 1; i<=n; i++) {
            if(i%2 != 0) {
                array.add(i);
            }
        }
        
        int[] answer = array.stream().mapToInt(Integer::intValue).toArray();
        
        return answer;
    }
}
```

answer에 배열을 반환해야 하는데, 문제를 풀면서 배열에 몇 개의 값이 들어갈지 모르기 때문에 `ArrayList`를 사용했다.

- `ArrayList`
    - Java에서 제공하는 크기가 동적으로 변하는 배열 기반의 자료구조

    - 처음에 요소의 개수를 지정하지 않아도 됨
        - 요소 추가하면 필요에 따라 내부 저장 공간이 자동으로 확장됨

    - `arr.size()`로 요소 개수 확인

    - `int`, `double` 같은 기본 자료형을 타입 인자로 사용할 수 없음
        - `int` 대선 래퍼 클래스인 `Integer`를 사용함

- `int[] answer = array.stream().mapToInt(Integer::intValue).toArray();`
    - `stream()` → 리스트의 요소를 순서대로 처리할 수 있도록 `Strem` 생성

    - `mapToInt(Integer::intValue)` → `Integer` 객체들을 기본 자료형 `int` 값으로 변환

    - `toArray()` → 변환된 값들을 배열에 담아 반환

### 외계행성의 나이

<a class="notion-mention" href="https://school.programmers.co.kr/learn/courses/30/lessons/120834">Programmers Java 기초</a>

#### 풀이

```java
class Solution {
    public String solution(int age) {
        String answer = "";
        
        String alpha = "abcdefghij";
        
        String str = String.valueOf(age);
        
        for (int i = 0; i < str.length(); i++) {
            int num = str.charAt(i) - '0';
            answer += alpha.charAt(num);
        }
        
        return answer;
    }
}
```

- 숫자를 문자열로 변환<br>
    `String str = String.valueOf(age);` → 숫자를 문자열로 변환해 `charAt()`을 이요해 각 자릿수에 접근할 수 있게됨

- 문자를 숫자로 변환<br>
    `int num = str.charAt(i) - '0';` → `charAt()`은 `char` 타입을 반환함
    ⇒ 필요한 건 정수형 숫자 인덱스! → **Java에서 문자끼리 빼기 연산을 하면 유니코드 값을 기준으로 계산**해주기 때문에 `‘2’ - ‘0’`과 같이 숫자 문자를 정수로 변환해줌
